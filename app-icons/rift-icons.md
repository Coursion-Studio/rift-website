# Rift — Feature Glyphs

Soft-3D cut-out icons for the Rift website feature cards. One glyph per feature.
Every prompt inherits the House Style below.

Save to: icons/feature

## House Style

```
Modern macOS-style app glyph, soft 3D rendering with subtle volumetric shading,
rounded glossy edges, gentle inner glow, premium and friendly. Single subject,
centered, filling ~78% of the frame. IMPORTANT: the subject is fully isolated on
a 100% transparent background — real alpha channel, absolutely no backdrop, no
gradient, no floor, no studio background, no shadow plate, no border, no text.
Cut-out sticker style. Output: 1024×1024 PNG, transparent.
```
